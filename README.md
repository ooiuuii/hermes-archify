# Hermes Archify

An independent Hermes extension for source-grounded, interactive architecture
diagrams, powered by [Archify](https://github.com/tt-a1i/archify).

Hermes understands the repository. Archify checks and renders the diagram.
This extension connects the two without patching Hermes core.

Initial development is in progress. Installation and verified demo instructions
will be included before the first release.

Community project; not an official Nous Research or Archify product.
