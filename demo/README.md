# Recorded demo stage

This static page is a presentation surface, not a Hermes product interface or a
live model session. It displays the actual saved HTML and sanitized execution
receipt generated by this repository. There are no simulated replies, automatic
progress animations, external fonts, CDNs, or automatic slide transitions.

Serve the repository root with a local HTTP server, then open `/demo/`. Do not use
`file://`: the receipt is loaded with a same-origin fetch. The proof section needs:

- `artifacts/demo/architecture.html`: the actual generated, interactive artifact.
- `artifacts/demo/receipt.public.json`: a sanitized receipt, without private paths,
  repository contents, credentials, or raw logs.

The stage presents only selected result, engine, artifact name, SHA-256, and check
fields. Missing values remain **Not available**; an unavailable receipt is visibly
reported. It does not verify the displayed hash itself: the receipt records the
execution evidence. Authored source grounding is not runtime-topology proof, and
deterministic checks are not a substitute for visual inspection.

## Capture

Use a 1920 × 1080 browser viewport and record only the demo page surface. Use the
visible **Intro**, **Evidence**, and **Get started** buttons or the left/right arrow
keys. Direct scene links are `/demo/#intro`, `/demo/#proof`, and `/demo/#outro`.
When the embedded viewer has keyboard focus, click the outer stage before using
its navigation shortcuts. The generated viewer remains interactive.

Suggested 75-second edit:

| Time | Scene |
| --- | --- |
| 00–18 | Intro: source → authored model → checked HTML and receipt |
| 18–58 | Evidence: inspect the actual diagram, then the saved receipt |
| 58–75 | Get started: repository, explicit installation, scope boundary |

`captions.zh.srt` provides optional Chinese captions for this suggested pacing.
Keep captions separate during capture and adjust them to the final edit. Do not
cover the artifact or receipt with subtitles. No narration or music is required.
Do not label saved evidence as a live model run; retain **Recorded execution ·
saved receipt** on screen. Any separately recorded real execution must be labeled
accurately, especially if waiting time is trimmed.

This directory does not start servers, generate artifacts, record a browser,
upload content, or publish anything. Follow the repository README for installation
and the verified artifact-generation workflow.
