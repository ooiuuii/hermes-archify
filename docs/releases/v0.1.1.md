# Hermes Archify v0.1.1

A verified source-grounded authoring update, with the new V5 native-vs-plugin demo.
The engine remains pinned to official Archify **2.16.0**. No Hermes core patch,
extra hosted service, automatic upload, or renderer replacement is introduced.

## Use it

Follow the [installation and activation instructions](https://github.com/ooiuuii/hermes-archify#install).
Restart affected Hermes sessions after updating. Load `hermes-archify:archify`
explicitly, or install/update the separate ordinary skill for discovery and `/archify`.
The model needs source-file access, and tool files must exist on the Hermes host.

## What changed

- Doctor exposes the pinned common schema and authoring-guide paths.
- The skill collects the actual repository URL, pinned revision and component
  source ranges before validation; it does not discard references to hide errors.
- Windows file-path fallback and normal terminal-approval handling are documented.
- The 3:19 Chinese V5 demo with Xiaoxiao narration distinguishes orange **A: native HTML/SVG** from green
  **B: plugin-driven interactive diagrams**, with real continuous browser recordings.
- The native example was freshly generated by Hermes using its own unmodified
  `architecture-diagram` skill. Its HTML and browser screenshot are included, alongside the previously
  supervised plugin output and its editable JSON.

## What “verified” means

See the [validation report](https://github.com/ooiuuii/hermes-archify/blob/main/docs/verification.md)
for real-engine tests, isolated Hermes loader/registry checks, browser evidence,
platforms and limitations. The real source-grounded Hermes diagram passed **9/9**
engine checks with **34** verified file/line references at its recorded revision.
The authored model was supervised; neither reference checks nor browser success
prove that every architectural relationship is semantically correct.

No private agent transcript, profile database, credentials, or raw run logs are
published. Public text evidence uses normalized source paths. Generic project paths
already visible in approved diagrams/video are retained; no account-specific home
path is present in those visuals. Public-file hashes identify any normalized copies
separately from the original generation receipts.

This is an independent community extension, not an official Nous Research or
Archify release. Teknium's inspected PR images did not identify their generating
skill; this release makes no attribution or endorsement claim.
